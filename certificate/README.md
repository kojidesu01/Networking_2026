# Certificates · Cisco Networking Academy

**สถานะ:** ยังไม่มีใบ Certificate แนบในโฟลเดอร์นี้

เมื่อมีเอกสารจริง ให้เพิ่มไฟล์ PDF หรือรูปภาพ พร้อมชื่อหลักสูตร วันที่ออกเอกสาร และลิงก์ตรวจสอบที่เผยแพร่ได้ (ถ้ามี) จากนั้นอัปเดตรายการใน README นี้ โดยตรวจข้อมูลส่วนบุคคลก่อนเผยแพร่
